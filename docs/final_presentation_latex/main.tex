\begin{frame}{Appendix -- Gradient Boosting Machine}
    Fitting Algorithm~\cite{hastie_2001_elements}:
    \begin{enumerate}
        \item Start with simple model, e.g. mean of target variable \\
        $F_1(x)=f_1(x)=\bar{y}$
        
        \item Calculate error gradient \\
        $\hat{r}_{mi} = -\left. \frac{\partial \mathcal{L}(y_i, F(x_i))} {\partial F(x_i)} \right|_{F = F_m} \quad \forall i \in \{1,\dots,N\}]$
        
        \item Fit a new weak learner to the residuals \\
        $f_{m+1}(x) \approx \hat{r}_m$
        
        \item Determine how much of the new learner to add \\
        $\gamma_{m+1}=\arg\min_{\gamma}\sum_{i=1}^{N}\mathcal{L}\bigl(y_i,F_m(x_i) + \gamma f_{m+1}(x_i)\bigr)$

        \item Update the model \\
        $F_{m+1}(x)=F_m(x)+\gamma_{m+1} f_{m+1}(x)$
    \end{enumerate}
    LightGBM uses leaf-wise tree growth, leaf with the highest loss reduction is split~\cite{shi_2025_lightgbm}
\end{frame}

\begin{frame}{Appendix -- Cyclic Encoding}
    \begin{columns}
        \begin{column}{0.48\textwidth}
            \begin{itemize}
                \item Cyclic encoding represents time features using sine and cosine functions~\cite{pedregosa_2011_scikit}
                \item Preserves continuity, e.g.\ the distance between 23:00 and 00:00 equals that between consecutive hours
                \item Helps the model capture periodic temporal patterns
            \end{itemize}
        \end{column}

\begin{frame}{Appendix -- SHapley Additive exPlanations Values}
    \begin{columns}
        \begin{column}{0.48\textwidth}
            \begin{itemize}
                \item SHAP values quantify how much each feature contributes to an individual prediction compared to a baseline.
                \item They are based on concepts from cooperative game theory and provide consistent and interpretable feature attributions.
            \end{itemize}
        \end{column}
